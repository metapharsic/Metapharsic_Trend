# Phase 1: MVP (Minimum Viable Product)

This document tracks the tasks and checkpoints for Phase 1.

## Deliverables
- [ ] Daily Call Reporting (DCR)
- [ ] Tour Planning (TP)
- [ ] Doctor CRM (Basic Profiling)
- [ ] Attendance (Geo-fenced check-in)
- [ ] Basic Reports (DCR Summary)

## Technical Checkpoints
- **Database Schema**: Ensure tables for `User`, `Employee`, `Territory`, `Doctor`, `Visit`, and `Attendance` are deployed.
- **Backend API**: Endpoints for authentication, DCR logging, and TP submission.
- **Mobile Integration**: Offline queue capability for DCR submission when connectivity is low.
